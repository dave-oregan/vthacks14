# sightline.surf (GitHub Pages)

This folder is the static public site for **https://sightline.surf**.

## Enable Pages

Repo **Settings → Pages**:

- Source: **Deploy from a branch**
- Branch: `main` / **`/docs`**
- Custom domain: `sightline.surf`

`CNAME` in this folder must stay as:

```
sightline.surf
```

## DNS

Point the apex domain at GitHub Pages (A/AAAA records) and optionally `www` → `dave-oregan.github.io`. See the root README for the exact record table.
